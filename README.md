# ppixiv 中文与现代界面

[ppixiv](https://github.com/ppixiv/ppixiv) 的配套油猴脚本，提供简体中文界面、中文标签译名和深浅色主题，也支持作品筛选、标记看过的作品、自定义下载文件名、高清缩略图和原图预加载。ppixiv 仍从 Greasy Fork 单独更新。

## 安装

1. 安装 Tampermonkey 和 [ppixiv](https://github.com/ppixiv/ppixiv)。
2. 打开 [脚本安装链接](https://raw.githubusercontent.com/Stevey233/ppixiv-zh/main/dist/ppixiv-zh.user.js)，在 Tampermonkey 页面确认安装。
3. 打开 Pixiv，进入 ppixiv 界面。

Tampermonkey 会通过 `dist/ppixiv-zh.meta.js` 检查版本，有新版本时自动更新。

如果装过 0.8.0 或更早的版本，安装后请在 Tampermonkey 中删除旧脚本。新版本更换了 namespace，脚本管理器会把它当作另一个脚本，两份同时启用会重复运行。

## 设置

搜索页外观按钮右边的按钮打开设置面板。电脑上按钮在顶部工具栏，手机和 iPad 上在底部导航栏。

| 设置 | 选项 | 默认 |
| --- | --- | --- |
| 外观 | 深色、浅色、跟随系统 | 深色 |
| 标签译名 | 中文、英文 | 中文 |
| 高清缩略图 | 自动、关闭 | 自动 |
| 悬停预加载原图 | 开启、关闭 | 开启 |
| 看过的作品 | 调暗、只记录、不记录 | 调暗 |
| 下载文件名 | 模板 | 留空，使用 ppixiv 的文件名 |

外观和外观按钮是同一个设置。标签译名切换后，之后显示的标签使用新的语言，已经显示的标签刷新后更新。设置保存在浏览器的 localStorage 中，键名以 `ppx-zh-` 开头，删除这些键即可恢复默认。看过的作品另外记录在 IndexedDB 中，用面板里的 "清除记录" 删除。图片翻译的语言是 ppixiv 自己的设置，在 ppixiv 的翻译设置里修改。

## 界面和标签

菜单、按钮、提示、设置和消息显示为简体中文，相对时间显示为 "3 小时前"。作品标题、用户名、标签、作品说明和保存的搜索分组名保留原文，ppixiv 的更新日志也保留原文。

工具栏、信息面板、菜单和对话框使用半透明背景，按钮和缩略图使用圆角，设置中的复选框显示为开关。中文字体优先使用系统已安装的 MiSans、HarmonyOS Sans、苹方和 Noto Sans CJK SC。

搜索页齿轮左侧的按钮按深色、浅色、跟随系统的顺序切换。电脑上按钮在顶部工具栏，手机和 iPad 上在底部导航栏。默认深色，选择会保存在浏览器中。

标签优先显示 Pixiv 返回的中文译名。日文标签没有中文译名时使用英文；中文或纯汉字标签没有含汉字的译名时保留原标签，例如 "原神" 不会显示成 Genshin Impact。中文译名需要先在搜索、推荐等页面收到，同一标签的英文数据不会覆盖已保存的中文译名。

在搜索框输入中文时，补全列表会列出中文译名匹配的日文标签。例如输入 "碧蓝" 会列出译名为碧蓝航线的 アズールレーン 和译名为碧蓝档案的 ブルーアーカイブ。补全项显示中文译名，后面用灰色小字显示原标签，可以和同名的中文标签区分开。Pixiv 的补全接口只在请求带语言参数时按译名匹配，ppixiv 不带这个参数，脚本会加上 `lang=zh`。补全项的译名包含输入的中文时，这个译名会补进还没有中文译名的标签。标签译名设为英文时不做这些改动。

ppixiv 的图片翻译默认译成英文，脚本把它改为简体中文。如果已经在 ppixiv 的翻译设置里选过语言，脚本不会改动。

## 作品筛选

推荐作品、关注用户的新作和收藏三个页面可以按类型筛选，选项是全部类型、插画、漫画，插画包含动图。三个页面的选择分别保存在浏览器中。

推荐作品页还有一行筛选按钮：竖图、横图、单页、多页、隐藏 AI、隐藏已收藏、隐藏看过的。竖图和横图只能选一个，单页和多页也只能选一个，再点一次取消。宽高相等的作品既不算竖图也不算横图。

筛选在本地进行，所以每批结果可能少于未筛选时。如果一批结果中没有符合条件的新作品，脚本会继续请求，最多共 4 次。ppixiv 已经显示过的作品不算新作品。推荐作品每次请求都会得到不同的作品；关注用户的新作和收藏则请求后面的页，ppixiv 加载下一页时从跳过的页之后接着请求。仍没有时停止加载并提示。请求出错时，错误照常交给 ppixiv。重试期间改变筛选或离开页面会停止重试，这一批结果不筛选，原样交给 ppixiv。

关注用户的新作和收藏会记住 ppixiv 的每一页对应 Pixiv 的哪几页，保存在当前标签页的 sessionStorage 中。刷新、从当前页刷新，以及带页码重新载入页面时，这一页从原来的位置开始，往上加载的页也回到各自原来的位置。从没加载过的页码打开时，ppixiv 往上加载的页每页只请求一次，没有符合条件的作品时原样显示，因为空页会让 ppixiv 停止加载后面的页。

自己的收藏选 "全部" 时，ppixiv 每页分别请求公开和非公开收藏，其中一边没有作品时就不再请求那一边。所以一边连续 4 页没有符合条件的作品时，脚本不让它结束，另一边照常加载。两边都没有时才停止加载并提示。

ppixiv 会保留同一页面每种视图已经加载的列表，例如推荐作品的全部和 R18、收藏的公开和非公开，回到这个视图时接着使用。列表一直使用开始加载时的筛选，筛选按钮显示的也是它的筛选。所以在别的视图或其他标签页改了筛选后，回到已经加载过的列表时仍是原来的筛选，点筛选按钮或刷新后才换成新的。

收藏页开启随机排序时不筛选，类型按钮也会隐藏。随机排序按乱序加载各页，跳过的页无法接续。相似作品页不使用筛选。

## 看过的作品

在看图界面打开过的作品记录在浏览器的 IndexedDB 中，搜索结果里它们的缩略图变暗，鼠标移上去时恢复。漫画分页里的缩略图不变暗。一个标签页打开的作品，其他标签页会同步变暗。记录超过 5 万个时，下次进入 ppixiv 会删除最久没有打开过的。

设置面板里可以选择 "只记录"，继续记录但不调暗；选 "不记录" 时既不调暗，也不记录新打开的作品，已有的记录保留。面板里也可以清除全部记录。推荐作品页的 "隐藏看过的" 使用同一份记录。

## 看图和右键菜单

桌面端双击图片不会进入浏览器全屏。需要全屏时按 F11，或点右键菜单的全屏按钮。移动端和 iPad 的双击缩放照常使用。

按住右键打开菜单，再用左键点对应按钮：

- 收藏并下载原图，替换原来的收藏标签按钮。收藏的公开范围跟随 ppixiv 的默认设置，已收藏的作品不会重复收藏。单张作品下载原图，多页作品下载全部页的 ZIP，动图下载 MKV。收藏标签仍可在作品信息面板里编辑。
- 相似作品，替换原来的点赞按钮，打开与 "更多 > 相似插画" 相同的页面。点赞仍可在作品信息面板中操作，也可按 Ctrl+V。

## 下载文件名

ppixiv 下载的文件默认命名为 "作者名 - 作品 ID - 标题"，单独下载多页作品的某一页时，ID 后面加 " #页码"。在设置面板填写模板后，脚本按模板给 ppixiv 下载的文件改名。可用的变量：

- `{author}` 作者名
- `{author_id}` 作者 ID
- `{id}` 作品 ID
- `{title}` 标题
- `{page}` 页码，从 1 开始。ZIP 和动图的 MKV 没有页码，为空
- `{pages}` 总页数
- `{date}` 投稿日期，例如 2024-01-02

`< >` 里有值为空的变量时，整段省略。例如模板 `{id}<_p{page}> {title}` 下载单张图片得到 `123456789_p1 标题.png`，下载 ZIP 得到 `123456789 标题.zip`。文件名中的 `\ / : * ? " < > |` 换成 `_`，扩展名之前的部分超过 180 个字符时截断。模板留空时使用 ppixiv 的文件名。ZIP 里各页的文件名不变。

## 缩略图和预加载

缩略图按屏幕上的实际像素大小选择 WebP 尺寸，包含系统缩放和浏览器缩放。三档分别为 `600x1200_90_webp`、`1200x1200_80_webp`、`1200x1200_90_webp`，每张通常约 40 到 180 KB。改变缩略图大小或浏览器缩放时，ppixiv 会重建缩略图。新缩略图先显示这张图已经下载过的尺寸，需要更大的尺寸时在后台下载，加载完再替换。漫画分页里先显示 ppixiv 已经下载的原缩略图，再在后台换成 WebP。

脚本根据最近 40 张缩略图的下载时间估算网速，并折算同时下载的数量。单张估计耗时超过 0.4 秒时不用最高画质，超过 1 秒时只用最小的 WebP 尺寸，它仍比 ppixiv 原来的缩略图稍大；网速恢复后重新检查可见缩略图。浏览器开启节省流量时保留 ppixiv 原来的缩略图。

某张图加载较大尺寸失败时，首次加载会回到 ppixiv 原来的缩略图，后台升级则保留当前图片。脚本随后绕过缓存请求一次 ppixiv 原来的缩略图，确认网络正常，再重试同一个 URL。重试仍失败才算失败，本次浏览不再请求该 URL；请求不通、浏览器处于离线状态，或重试成功，都不算失败，之后照常使用高清版本。重建缩略图不会重复计数，累计 5 个不同 URL 失败后停止新的高清请求和升级。

鼠标移到缩略图上并停留 0.3 秒后，脚本请求作品信息并预加载原图，也会下载看图时先显示的 540 预览图。鼠标不动、只滚动页面时不会触发。看多页作品时，当前页加载完后再预加载后面的页，跟随 ppixiv 的 "预加载漫画" 设置：所有分页时预加载后面 2 页，附近的分页时预加载下一页，只预加载缩略图时不预加载。ppixiv 在手机和 iPad 上默认只预加载缩略图。图片预加载最多同时进行 3 个，新请求会取消最旧的未完成请求；悬停触发的预加载每分钟最多 30 次，不需要下载任何东西的悬停不计入。

被屏蔽的作品不预加载，动图只下载 540 预览图，浏览器开启节省流量时关闭预加载。悬停过但没有点开的作品也可能下载原图，因此这个功能会增加流量。悬停预加载可以在设置面板中关闭，看多页作品时的预加载仍跟随 ppixiv 的 "预加载漫画" 设置。

## 修改和构建

源文件在 `src/`：

- `dict.js` 保存翻译词典、带变量的句式和不翻译的区域。
- `theme.css` 保存主题样式，规则限定在 `html.ppx-zh` 下。
- `main.js` 处理翻译、主题、设置面板和功能扩展。
- `header.js` 保存油猴脚本信息和版本号。

脚本在页面环境中运行。ppixiv 会替换 `setTimeout`、`fetch` 和 `createElement`，因此定时器和请求使用它保留的接口，主题通过 `document.adoptedStyleSheets` 注入。检测到 ppixiv 界面后才启用主题，界面翻译限定在带 `widget` 类的元素内。

构建不需要安装依赖：

```sh
node build.mjs
```

构建会生成 `dist/ppixiv-zh.user.js` 和只含脚本头的 `dist/ppixiv-zh.meta.js`。发布时提高 `src/header.js` 中的 `@version`，重新构建，并把两个生成文件一同提交。

## 测试

测试在 Node.js 中运行：

```sh
node test/unit.mjs
node test/thumbnails.mjs
node test/tag-translations.mjs /path/to/ppixiv/web/vview/misc/tag-translations.js
```

`unit.mjs` 检查界面文字和句式的翻译、作品筛选和跳过页后的接续、请求 URL、网速估算、标签译名选择和下载文件名。`thumbnails.mjs` 检查失败去重和重试确认、重建元素后的降级和已下载尺寸的复用、停用后是否仍发起升级或替换图片、失败退回后重新测量宽高比、缩放缩略图、漫画分页和节省流量模式的尺寸选择。

`tag-translations.mjs` 使用 ppixiv 的实际 `TagTranslations` 类，检查并发更新是否保留中文、搜索补全的中文译名是否只补进缺少中文译名的标签、选择英文后是否使用 ppixiv 原来的查询、写入失败后能否继续保存，以及 IndexedDB 不可用时的会话缓存。省略源码路径时，默认读取 `~/scratch/ppixiv-src/repo/web/vview/misc/tag-translations.js`。

排查漏翻译的文字时，可在脚本开头加入 `var PZ_DEBUG = true;`，然后在页面控制台执行 `document.dispatchEvent(new Event("pz-dump"))`。结果保存在 `document.documentElement.dataset.pzMissing`。
